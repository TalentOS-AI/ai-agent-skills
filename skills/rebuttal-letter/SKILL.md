# Rebuttal / response to reviewers
1. Split every review into atomic points and give each an ID (R1.1, R2.3, ...). Tag each as factual misunderstanding / request for experiment / clarification / disagreement / minor.
2. Decide priorities: answer first the points that drive the scores and the meta-review. Run cheap requested analyses if time allows.
3. Write each answer as: short thanks or acknowledgment, then a direct answer, then evidence (a new number, a quote with section and line, a citation), then the concrete change ("we will add X to Section 4"). Keep it polite and specific, never defensive.
4. Conference rebuttals: respect the character limit, open with a general response covering shared concerns, and don't add new results the venue forbids. Journal letters: quote each comment, reply, and point to tracked changes by page and line.
5. Check every claim against the paper. Don't promise anything you can't deliver for camera-ready.
6. Point out a factual reviewer error once, neutrally. Raise serious issues with the AC through the official channel only.
